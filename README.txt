# Hafiz Abdullah — Developer Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — dark modern orange/white design
- `script.js` — mobile navigation, current year, and contact form validation
- `assets/profile.svg` — temporary profile illustration

## Run locally
1. Extract the ZIP file.
2. Open the `hafiz-abdullah-portfolio` folder.
3. Double-click `index.html` to open it in your browser.
4. Internet is needed for the Bootstrap CDN and Bootstrap Icons.

## Personalize before publishing
1. Replace `assets/profile.svg` with your own portrait photo named `profile.jpg`.
2. In `index.html`, change the image path to `assets/profile.jpg`.
3. Replace `your.email@example.com` in `index.html` and `script.js` with your real email.
4. Replace the `#` links for GitHub, LinkedIn, and project links with your actual URLs.
5. Update project descriptions and add screenshots of your real projects.
6. Update the About section so it accurately describes your experience and current skill level.

## Important contact form note
The form currently validates the fields and opens the visitor's default email application using `mailto:`.
It does not save messages to a database or send them silently. To receive messages directly on your website,
connect a PHP backend and validate the data server-side before inserting it into MySQL or sending email.

## Suggested XAMPP location

`D:\\xampp\\htdocs\\hafiz-portfolio`
